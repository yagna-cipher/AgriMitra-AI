## 📌 About the Project

AgriMitra AI is an AI-based agricultural application developed to explore how artificial intelligence can make agricultural information more accessible to farmers.

The application provides a farmer-friendly interface with crop health indicators, urgent crop alerts, and multilingual interaction. It aims to make agricultural technology easier to access and use.

## 🎯 Problem Statement

Farmers may face challenges accessing timely agricultural information, understanding crop-related risks, and using digital platforms that support their preferred languages.

AgriMitra AI explores an AI-driven approach to addressing these challenges through an accessible, interactive agricultural assistant.

## ✨ Key Features

- 🌾 **AI-Powered Agricultural Assistance:** Supports access to agricultural information through AI.
- 📊 **Crop Health Dashboard:** Displays crop health indicators and an overall score.
- 🚨 **Crop Alerts:** Highlights potential crop-related risks and urgent alerts.
- 🌍 **Multilingual Interface:** Provides language selection for a more accessible user experience.
- 🌱 **Farmer-Friendly Design:** Presents agricultural information through an interactive dashboard.
- 🤖 **Gemini AI Integration:** Uses Gemini-powered capabilities where configured in the application.

*Note: Features and outputs depend on the application's implementation and configuration.*

## ⚙️ Run Locally

### Prerequisites

- Node.js
- npm
- A Gemini API key, if required by the application

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yagna-cipher/AgriMitra-AI/edit/main/README.md
   ```

2. Navigate to the project directory:

   ```bash
   cd AgriMitra-AI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env.local` file in the project root and add your API key:

   ```env
   GEMINI_API_KEY=your_gemini_api_key
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown in your terminal.

**Security:** Never commit `.env.local` or expose your API key in source code. Make sure secret files are excluded through `.gitignore`.
